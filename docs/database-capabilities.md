# 逐库能力矩阵

下表是首版实现目标，**不是已实现功能清单**。具体版本、驱动和部署配置仍待固定；能力探测结果必须影响 UI 与 AI 可调用操作。

## 浏览与原生操作

| 数据库 | 工作台展示 | 原生操作入口 | 首版代表性操作 |
| --- | --- | --- | --- |
| MySQL | 库表树、字段、约束、索引、建表语句、行数据 | SQL 编辑器 | 查询与增删改、批量建表、常见字段及索引变更 |
| MongoDB | 库与集合、文档、索引、校验规则、抽样字段概览 | 查询条件、更新表达式、聚合管道 | 集合创建、文档增删改查、聚合、索引管理 |
| Redis | Key、类型、TTL、值及集合成员 | 原生命令及命令批次 | String、Hash、List、Set、Sorted Set 的读写与过期设置 |
| Cassandra | Keyspace、表、列、分区键和聚簇键 | CQL 编辑器 | 建表、按主键访问与修改、符合数据模型的查询 |
| Neo4j | 标签、节点、关系类型、属性、索引、受限规模图形预览 | Cypher 编辑器 | 节点与关系创建、查询、修改和删除 |
| InfluxDB | 数据库对象、时间字段、标签、字段、时间范围内记录 | 选定版本支持的原生查询语言 | 时序写入、时间范围查询、聚合与简单趋势预览 |
| Elasticsearch | 索引、Mapping、文档和搜索结果 | REST 请求与 Query DSL | 创建索引、批量写入、检索、聚合、文档修改 |
| ClickHouse | 数据库、表、列、表引擎和查询结果 | SQL 编辑器 | 建表、批量写入、分析查询及选定版本支持的修改操作 |
| Milvus | 集合、Schema、向量维度、标量字段、索引和检索结果 | 结构化查询与检索请求 | 建集合、写入、标量过滤、相似度检索和删除 |

MongoDB 抽样字段必须标明抽样范围，不能当成完整 Schema。Redis 浏览采用增量扫描，不默认执行全量 KEYS。图预览限制节点与边数量。向量检索展示距离或得分及所用度量，不能统一标成百分比相似度。

## 导入目标

| 数据库 | 首版建议输入 | 必须明确的映射 |
| --- | --- | --- |
| MySQL | CSV、Excel | 表名、字段、类型、主键、空值和日期处理 |
| MongoDB | JSON、JSONL | 集合、文档结构、标识字段、嵌套内容 |
| Redis | JSON、CSV | Key 构造、数据类型、值映射和 TTL |
| Cassandra | CSV、JSONL | Keyspace、表、列类型、分区键和聚簇键 |
| Neo4j | 节点/关系 CSV 或约定结构 JSON | 节点标识、标签、关系方向与端点匹配 |
| InfluxDB | CSV、Line Protocol | 时间戳与精度、标签、字段、目标对象 |
| Elasticsearch | JSONL、JSON | 索引、文档 ID、Mapping |
| ClickHouse | CSV、JSONL | 表结构、表引擎、排序键、字段类型 |
| Milvus | 含数值向量的 JSON、JSONL | 主键、向量字段与维度、标量元数据、距离度量 |

文件格式和容量上限在实现前确定并写入接口约束。任意文件自动变成任意数据库模型不属于承诺范围。

Milvus 首版以已有向量的数据导入和检索为验收基线。文本自动向量化需要额外的 Embedding 模型选型，不默认扩展为 RAG 产品。

## 修改与恢复边界

| 数据库 | 执行前必须说明的边界 |
| --- | --- |
| MySQL | 事务型 DML 与 DDL 分开处理；建表或改表不承诺整批事务回滚 |
| MongoDB | 多文档事务根据部署能力启用；普通批量写入不能自动视作一个事务 |
| Redis | 命令批次及 MULTI/EXEC 不等于 SQL 式出错回滚；恢复需要另行设计 |
| Cassandra | BATCH 不提供任意操作的通用撤销；不将其包装成通用 SQL 事务 |
| Neo4j | 支持范围内使用事务；提交后的恢复依赖补偿方案与冲突检查 |
| InfluxDB | 以选定版本的写入、删除及更新能力为准；不承诺通用改表与回滚 |
| Elasticsearch | Bulk 需要检查每项结果；写入成功与搜索可见状态应区分 |
| ClickHouse | 根据版本和操作区分同步完成与异步变更，不能把任务提交视作变更完成 |
| Milvus | 按实际一致性和可见性语义核验写入，不承诺关系型数据库式事务回滚 |

## 版本验证要求

每个适配器落地时补充：固定版本、官方驱动、支持的部署形态、可执行操作清单、限制、真实集成测试及官方文档依据。以上边界需要在该版本上复核，不能只靠提示词约束。
